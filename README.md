# 枫叶岛冒险

一个横版卷轴的网页 RPG 小游戏，画面全部用 Canvas 2D 程序化绘制（无图片素材），单个 `index.html` 文件，双击即可在浏览器中游玩。

## 玩法

- 三个职业，开始界面选择，之后可在「说明」里随时切换：
  - **剑士**：近战、血厚，技能「连斩」同时砍 5 只，增益「愤怒之火」
  - **弓箭手**：远程、暴击高，技能「穿透箭」射穿一排，增益「集中术」
  - **魔法师**：法杖发射魔法弹，技能「雷电术」召唤落雷劈中前方最多 6 只怪，增益「魔法盾」减伤 40%
- 四张地图，通过地图两端的传送门往返（↑ 进入）：
  - **枫叶村 · 东郊狩猎场**（Lv.1+）：蜗牛、绿水灵、花蘑菇、蓝蘑菇，Boss 蘑菇王
  - **蘑菇森林 · 幽光深处**（Lv.10+）：毒蘑菇、树桩怪，Boss 树桩王
  - **冰雪峡谷 · 寒风坡**（Lv.20+）：雪球史莱姆、企鹅兵、小雪人，Boss 雪人王
  - **熔岩洞窟 · 炎魔巢穴**（Lv.30+）：熔岩史莱姆、会俯冲的火焰蝙蝠、熔岩魔像，最终 Boss **炎魔巴洛**
- 最终 Boss 炎魔巴洛会召唤陨石雨（落点先出现红色预警圈，及时躲开）和跳砸，血量低于一半时暴怒、攻击更频繁。第一次击败它会弹出通关画面，显示职业、等级、冒险用时、击败怪物数等统计；通关后可以继续刷怪、收集图鉴
- 终极技能（F / Shift / 4，Lv.30 二转后解锁，冷却 12 秒）：
  - 剑士「破天斩」：高举大剑劈向地面，冲击波横扫前方最多 10 只怪物
  - 弓箭手「箭雨」：朝天射出一轮箭，箭雨覆盖前方一大片区域
  - 魔法师「流星火雨」：召唤三颗陨石砸向前方，大范围爆炸
- 宠物：在商店领养「小猪噜噜」或「雪兔棉棉」，会跟着你跑并自动捡起附近的金币和药水
- 怪物图鉴（右上角「图鉴」）：每种怪物击败 30 只（Boss 1 只）完成收集，每完成一种伤害永久 +1%
- 精英怪：小概率刷新，体型更大、发金光，血量 ×6，经验 ×5，掉落更多（每张地图同时最多 2 只）
- 村长委托：村口左边的「村长 · 枫奶奶」头上有 **!** 时可以接委托，**?** 时回去交任务。共 11 个委托贯穿四张地图：收集怪物掉落（蜗牛壳、水灵露珠、蘑菇伞……只有接了委托才会掉）或讨伐各地 Boss，奖励经验、金币和药水。左上角会显示当前委托进度；等级远高于委托要求时可以直接跳过
- 一转位移技能（Lv.10）：剑士和弓箭手在空中再按一次跳跃是「二段跳」，向前冲出一大段；魔法师是「瞬移」，向前闪现一段，按住 ↑ 则向上瞬移（耗少量 MP）
- 怪物会反击：被惹怒的树桩怪、小雪人、熔岩魔像会先蹲下蓄力（头上出现红色 **!**、身体闪红、地上出现红圈）再砸地，跳起来就能躲开；毒蘑菇、企鹅兵、熔岩史莱姆会先后仰蓄力再朝你抛出孢子、雪球、火球。Boss 跳砸前也会先蹲下并在地上画出落地范围
- 连杀：5 秒内连续击败怪物会累积连杀数（屏幕右侧显示），每满 10 连杀额外获得一份经验，连杀越高奖励越多
- 世界地图（M 或右上角「地图」）：查看四张地图的推荐等级、怪物和 Boss 讨伐情况，付金币坐传送石直接前往去过的地方
- 设置（右上角「设置」）：背景音乐、音效、屏幕震动开关，以及自动喝药（HP / MP 低于 30% 或 50% 时自动喝，类似宠物的自动喝药功能）
- 背景音乐：每张地图一首程序生成的循环曲；切到别的标签页时会自动静音并存档
- 左上角小地图：显示平台、绳子、传送门、商人、村长、Boss 和自己的位置
- 商店：村口的「老枫杂货铺」，走到商人旁按 ↑ 打开。可以买红/蓝药水，升级武器（6 档，攻击 ×1.0 → ×3.5）和防具（5 档，减伤 0 → 30），高档装备有等级要求，最高档「炎龙」系列需要 Lv.30
- 讨伐任务：每张地图各自计数，击败 50 只怪物后召唤该地图的 Boss
- 剑士普攻是三段连招（下劈 → 上撩 → 突刺），带刀光拖尾和命中停顿；弓箭手有拉弓、松弦回弹和蓄力光效
- 增益技能（V，Lv.5 起）：剑士「愤怒之火」攻击 +25%，弓箭手「集中术」暴击 +15%、攻击 +10%，持续 30 秒
- 10 级转职（剑客 / 猎人 / 魔法师），30 级二转（勇士 / 射手 / 大魔导士）并习得终极技能
- 进度自动保存在浏览器本地；标题页（右上角「说明」）可以「删除存档，重新开始」，需要连点两次确认

## 操作

| 按键 | 动作 |
| --- | --- |
| ← → | 移动 |
| ↑ ↓ | 爬绳子 |
| 空格 / C | 跳跃（↓ + 跳：跳下平台；空中再按：二段跳 / 瞬移，Lv.10 起） |
| X / Ctrl | 普通攻击（按住连续攻击） |
| Z | 职业技能（连斩 / 穿透箭 / 雷电术，耗 MP） |
| V / 3 | 增益技能（愤怒之火 / 集中术 / 魔法盾） |
| F / Shift / 4 | 终极技能（破天斩 / 箭雨 / 流星火雨，Lv.30 起） |
| ↑（在传送门处） | 前往其他地图 |
| ↑（在商人 / 村长旁） | 打开商店 / 对话，Esc 关闭 |
| M | 世界地图（传送） |
| 1 / 2 | 红药 / 蓝药 |

手机上会自动显示虚拟按键，建议横屏游玩。

## 手感与性能细节

- 跳跃有约 0.1 秒的「土狼时间」（刚走出平台边缘仍可起跳）和约 0.13 秒的跳跃缓冲（落地前一瞬按下也算数）；攻击、技能的快速轻点也会被短暂缓冲，不会因为按得太快而丢失
- 击败 Boss 时有短暂的慢动作
- 怪物受击闪白、蓄力闪红改用离屏画布着色，不再使用 `ctx.filter`：Boss 受击时单帧绘制从 100 ms 以上降到 1 ms 左右，Safari 上也能正常显示受击闪光和图鉴剪影
