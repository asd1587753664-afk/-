# 枫叶岛冒险

一个横版卷轴的网页 RPG 小游戏，画面全部用 Canvas 2D 程序化绘制（无图片素材），单个 `index.html` 文件，双击即可在浏览器中游玩。

## 玩法

- 两个职业：**剑士**（近战、血厚，技能「连斩」同时砍 5 只）和 **弓箭手**（远程、暴击高，技能「穿透箭」射穿一排）。开始界面选择，之后可在「操作说明」里随时切换
- 三张地图，通过地图两端的传送门往返（↑ 进入）：
  - **枫叶村 · 东郊狩猎场**（Lv.1+）：蜗牛、绿水灵、花蘑菇、蓝蘑菇，Boss 蘑菇王
  - **蘑菇森林 · 幽光深处**（Lv.10+）：毒蘑菇、树桩怪，Boss 树桩王
  - **冰雪峡谷 · 寒风坡**（Lv.20+）：雪球史莱姆、企鹅兵、小雪人，Boss 雪人王
- 左上角小地图：显示平台、绳子、传送门、商人、Boss 和自己的位置
- 商店：村口的「老枫杂货铺」，走到商人旁按 ↑ 打开。可以买红/蓝药水，升级武器（5 档，攻击 ×1.0 → ×2.7）和防具（4 档，减伤 0 → 18），高档装备有等级要求
- 讨伐任务：每张地图各自计数，击败 50 只怪物后召唤该地图的 Boss
- 剑士普攻是三段连招（下劈 → 上撩 → 突刺），带刀光拖尾和命中停顿；弓箭手有拉弓、松弦回弹和蓄力光效
- 增益技能（V，Lv.5 起）：剑士「愤怒之火」攻击 +25%，弓箭手「集中术」暴击 +15%、攻击 +10%，持续 30 秒
- 10 级转职（剑客 / 猎人），30 级二转（勇士 / 射手）；进度自动保存在浏览器本地

## 操作

| 按键 | 动作 |
| --- | --- |
| ← → | 移动 |
| ↑ ↓ | 爬绳子 |
| 空格 / C | 跳跃（↓ + 跳：跳下平台） |
| X / Ctrl | 普通攻击（按住连续攻击） |
| Z | 职业技能（连斩 / 穿透箭，耗 MP） |
| V / 3 | 增益技能 |
| ↑（在传送门处） | 前往其他地图 |
| ↑（在商人旁） | 打开商店，Esc 关闭 |
| 1 / 2 | 红药 / 蓝药 |

手机上会自动显示虚拟按键，建议横屏游玩。
